# ผังดวงอาชีพ

แบบสำรวจความสนใจด้านเทคโนโลยีและอาชีพดิจิทัล · ชุดคำถามที่ 3 (Level 3)
หลักสูตรเทคโนโลยีสารสนเทศ มทร.ล้านนา ลำปาง · กิจกรรม "แม่หมอ VR"

ตอบ 6 ข้อ แล้วอ่านผลเป็น **ผังดวงหกแกน** ที่บอกว่าผู้ตอบเอนไปทางสายงานไอทีใด
เล่นบนมือถือผ่าน QR หรือบนเครื่องบูธที่เลือกคำตอบด้วยการยกมือหน้ากล้องก็ได้

---

## เริ่มใช้งาน

```bash
npm install          # ครั้งเดียว (ใช้แค่ตอนสร้าง QR)
npm run dev          # เปิด http://localhost:4173
npm run check        # สร้างไฟล์ใหม่ + ตรวจความถูกต้องทั้งหมด
```

## นำขึ้นออนไลน์

```bash
vercel login         # ครั้งเดียว เปิดเบราว์เซอร์ให้ยืนยันตัวตน
vercel link          # เลือกหรือสร้างโปรเจกต์บน Vercel
vercel deploy --prod # ได้ที่อยู่จริงสำหรับทำ QR
```

`vercel.json` ตั้งค่าไว้แล้ว: build ด้วย `npm run build` แล้วเสิร์ฟจาก `app/public`

## สร้างป้าย QR สำหรับพิมพ์

```bash
npm run qr -- https://ที่อยู่จริงของคุณ
```

ได้ไฟล์ใน `dist/qr/`

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `qr.svg` | เวกเตอร์ ขยายพิมพ์ใหญ่แค่ไหนก็คม |
| `qr.png` | 2048px สำหรับป้ายไวนิลหรือสไลด์ |
| `poster.html` | หน้า A4 เปิดในเบราว์เซอร์แล้วสั่งพิมพ์ได้เลย |

QR ใช้ระดับแก้ไขความผิดพลาด H (สูงสุด) เพราะป้ายที่บูธมักโดนแสงสะท้อนและถูกสแกนจากมุมเอียง

---

## สองโหมด

| | โหมดมือถือ (ค่าเริ่มต้น) | โหมดบูธ |
|---|---|---|
| เปิดด้วย | สแกน QR ตามปกติ | ปุ่ม "โหมดบูธ" หรือ `?mode=kiosk` ต่อท้ายที่อยู่ |
| เลือกคำตอบ | แตะหน้าจอ | แตะ · กดเลข 1–6 · **ยกมือหน้ากล้อง** |
| ตัวอักษร | ขนาดปกติ | ใหญ่ขึ้น (ผู้เล่นยืนห่างจอ) |
| ตัวเลือกบนจอกว้าง | คอลัมน์เดียว | สองคอลัมน์ เห็นครบโดยไม่ต้องเลื่อน |
| ชวนติดตั้งแอป | ชวน | ไม่ชวน |
| ไม่มีคนเล่นต่อ 60 วินาที | อยู่หน้าเดิม | กลับหน้าแรกเอง |

ทำลิงก์แยกสำหรับเครื่องบูธไว้เลยก็ได้ เช่น `https://ที่อยู่ของคุณ/?mode=kiosk`
ค่าที่เลือกถูกจำไว้ในเครื่อง เปิดครั้งต่อไปจึงยังเป็นโหมดเดิม

### คีย์ลัด (สำหรับเจ้าหน้าที่)

| ปุ่ม | ทำอะไร |
|---|---|
| `1`–`6` | เลือกคำตอบ |
| `Backspace` | ย้อนกลับหนึ่งข้อ |
| `L` | เปิดแผงบันทึกผู้เข้าร่วม |
| `Esc` | เริ่มรอบใหม่ (หรือปิดแผงบันทึก) |
| `Space` | ข้ามฉากประมวลผล |

คีย์ลัดอ่านจากตำแหน่งปุ่มจริง ไม่ใช่ตัวอักษรที่พิมพ์ออกมา จึงยังใช้ได้แม้เครื่องค้างอยู่โหมดภาษาไทย

## เล่นออฟไลน์

Service worker เก็บทุกไฟล์ไว้ตั้งแต่เปิดครั้งแรก (318 KB รวมฟอนต์)
หลังจากนั้นเล่นได้โดยไม่ต้องมีสัญญาณ — สำคัญมากเพราะ WiFi ในงานนิทรรศการมักล่มตอนคนเยอะ

**เงื่อนไขเดียว: การเปิดครั้งแรกต้องมีเน็ต** ผู้เข้าร่วมที่สแกน QR ครั้งแรกจึงควรอยู่ในจุดที่สัญญาณยังใช้ได้

ไม่มีการเรียกไฟล์จากภายนอกเลยแม้แต่ฟอนต์ — ทุกอย่างอยู่ในโดเมนเดียว

---

## ความเป็นส่วนตัว

- ไม่เก็บชื่อ นามสกุล โรงเรียน หรือเบอร์โทร
- บันทึกเฉพาะ วันที่ · เวลา · หมายเลขรอบที่ระบบสร้างเอง · ผลการสำรวจ · เวลาที่ใช้
- เก็บใน `localStorage` ของเครื่องนั้นเท่านั้น ไม่มีเซิร์ฟเวอร์ ไม่มีการส่งออก
- ภาพจากกล้องถูกย่อเป็น 96×54 แล้ววิเคราะห์ในหน่วยความจำ ไม่ถูกบันทึกและไม่ถูกส่งออก

เจ้าหน้าที่ดาวน์โหลดบันทึกเป็น CSV ได้จากแผง "บันทึกผู้เข้าร่วม"

## โครงสร้าง

```
app/public/            ← ทั้งหมดนี้คือสิ่งที่ถูก deploy
  index.html
  app.webmanifest
  sw.js                ← สร้างอัตโนมัติ อย่าแก้ด้วยมือ
  assets/fonts/        ← Trirong + IBM Plex (self-host เพื่อให้ออฟไลน์ได้จริง)
  assets/icons/        ← สร้างอัตโนมัติจาก build/make-icons.mjs
  src/
    data.js            ← ชุดคำถามและคำอธิบายผลทั้งหมด แก้ที่นี่ที่เดียว
    chart.js           ← แผ่นผังดวง (แผนภูมิเรดาร์)
    vision.js          ← ตรวจจับมือที่ยกค้าง สำหรับโหมดบูธ
    stats.js           ← บันทึกผู้เข้าร่วมและแผงสถิติ
    app.js             ← ตัวควบคุมลำดับฉาก
    styles.css         ← ระบบดีไซน์ทั้งหมด
build/                 ← สคริปต์ตอน build ไม่ถูก deploy
legacy/index-v1.html   ← รุ่นเดิมไฟล์เดียว เก็บไว้อ้างอิง
```

### แก้คำถาม

แก้ `app/public/src/data.js` ที่เดียว แล้วรัน `npm run check`

`check-balance.mjs` จะไล่ทุกเส้นทางคำตอบที่เป็นไปได้ (ตอนนี้ 12,000 เส้นทาง)
แล้วรายงานว่าแต่ละสายมีโอกาสออกกี่เปอร์เซ็นต์ ถ้าสายไหนต่ำผิดปกติแปลว่าคำถามเอียง

ปัจจุบันอยู่ในช่วง **13.8–19.4%** (อุดมคติคือ 16.7%)

คะแนนถูก normalize ด้วยเพดานของแต่ละแกนก่อนจัดอันดับเสมอ ดังนั้นการเพิ่มตัวเลือกที่ให้คะแนนสายใดสายหนึ่ง
จะไม่ทำให้สายนั้นได้เปรียบโดยอัตโนมัติ

## หมายเหตุด้านเทคนิค

**ไม่มีขั้นตอน build ของ JavaScript โดยตั้งใจ** — เป็น ES modules ล้วน เสิร์ฟตรง
บูธนี้ต้องยังใช้งานได้ในอีกหลายปีข้างหน้า การไม่มี bundler แปลว่าไม่มีอะไรให้ผุ
`npm run build` ทำแค่สองอย่าง: สร้างไอคอน PNG และสร้างรายการไฟล์ใน `sw.js` ใหม่

**`sw.js` มีเลขรุ่นที่คำนวณจากเนื้อไฟล์จริง** พอมีไฟล์ไหนเปลี่ยน แคชเก่าจะถูกลบทั้งชุด
เครื่องที่ติดตั้งไว้แล้วจึงไม่ค้างอยู่กับรุ่นเก่าโดยไม่มีใครรู้ตัว
